# 🎤 SkySoCover — каверы голосом через RVC

Кидаешь видео → музыка отделяется → голос перепевается выбранной RVC-моделью → музыка возвращается → готовый клип.

## 🧠 Как устроено (5 шагов)

```
видео → demucs (вокал отдельно, музыка отдельно)
      → анализ F0 + Gemma подбирает параметры зная голос
      → RVC-конвертация вокала (своя сборка инференса)
      → RMS-баланс + музыка назад → mux
```

| Шаг | Чем | Детали |
|---|---|---|
| Разделение | `demucs htdemucs` (GPU) | Два стема: `vocals` / `no_vocals`. Длинное режется по тишине на куски ≤150 сек |
| Тон | математика по F0 | Медиана исходника → медиана типа голоса (female 220 / male 120 / child 300), кап ±6 |
| Параметры | Gemma | `index_rate` (песни 0.4-0.6), `protect`, `rms_mix` — с обоснованием в логе |
| RVC | свой инференс v2 | Hubert-признаки + RMVPE-тон + faiss-индекс; ниже 0.4 index голос остается похож на оригинал |
| Микс | автобаланс | Фон = доля RMS голоса (песня 0.8, речь 0.4), слайдер сверху |

## 🖥 Требования

- Windows + Python 3.12 + **NVIDIA 8GB+**
- RVC-модели (`.pth` + `.index`) — свои, лежат отдельно (по умолч. `D:\ModelsVoice`)
- `rmvpe.onnx` для тона вокала (по умолч. из бандла MMVC)
- Веса Hubert `cover/_rvc/hubert_rvc.pt` — **в гит не влезли, качай из Releases → v1.0.0**
- ffmpeg в PATH. Бота и другие проекты на время кавера останавливай — видюха одна

## 🚀 Установка

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu130
.\.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env   # нужен только GOOGLE_API_KEY (для подбора параметров)
# положи hubert_rvc.pt из Releases в cover\_rvc\
.\.venv\Scripts\python cover\gui.py
```

После каждой генерации голос выгружается из VRAM сам. Ручки: тон (авто/слайдер ±12), index/protect (авто от Gemma или слайдеры), громкость музыки, сохранение.

## 📌 Из опыта (важно!)

- **Модель должна быть обучена на chinese-hubert признаках.** Проверено числами: популярный Hubert-порт с HuggingFace — *другая модель*, с ним выходит мусор. Поэтому в комплекте свои сконверченные веса из эталона.
- **Англоязычные модели русский поют с акцентом/кашей** (проверено на практике) — для русского бери русские модели.
- **Транспонирование больше ±6 рвет** — кап стоит в автотоне, руками выше не крути без нужды.
- **Index ниже 0.4** — голос почти не меняется, будешь слушать "оригинал". Для кавера держи 0.5-0.8.
- **Pyin для песен слабоват** — поэтому по умолчанию RMVPE (быстрый onnx, ~20x реалтайма на CPU).
- **TDR-вылеты** (гаснет монитор) = забитый VRAM: длинные файлы идут по кускам, перед стартом проверяется свободная память, при <2.5GB demucs едет на CPU.
